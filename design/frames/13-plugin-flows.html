C · Click a word, move the playhead

Proposed · host-dependent

A standard AU or VST3 insert reads the host clock but cannot move it. ARA 2 adds a playback controller that lets the plugin ask the host to set the playback position. Today the plugin is a standard insert, so this flow needs an ARA 2 build to do the jump; without it, the click shows exactly where to go.
