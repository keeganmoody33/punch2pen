Design system · v1 · 2026-09-30

Punch in.
Pen it.

One system for the DAW plugin and punch2pen.com: marker green sampled from the sketches, on the graphite chrome the plugin already ships. Fifteen artboards, built as Paper-ready HTML so they go straight onto a Paper canvas, with Paper’s own shaders where they earn it.

Green is liveAccent, primary action, PLAY, corrected, synced. #43C7A3 on graphite; the marker #2A6F5D on paper.
Red is RECRecording and nothing else in the product UI.
Amber is waitingWAIT, the engine banner, pending sync.
Ink is the plateThe word under the playhead is an ink plate, never a color fill.

Get it into Paper

Three steps on your Mac

  1. Open Paper Desktop with a new file. In its MCP panel, click Add to Claude, restart Claude Code, and check /mcp.
  2. In the punch2pen repo: git checkout claude/admiring-ride-xmdgph.
  3. Paste the prompt into Claude Code. It builds one artboard at a time and checks each against its render.

Paper’s MCP only runs on your own machine, which is why this step is yours. Full notes in design/PAPER.md.

PromptCopied 
Build the Punch2Pen design system in the Paper file that is open right now.

Source of truth: the HTML files in design/frames/ (skip files starting with "_").
Each file is one artboard. Its <meta name="paper:artboard"> tag gives the artboard
name, data-width and data-height.

1. First, create Paper color tokens from the "semantic" group in
   design/tokens/tokens.json (bg-deep, bg-pane, bg-chrome, bg-raised, ink, ink-2,
   ink-3, ink-4, accent, accent-ink, rec, wait, play, marker, pad-*). Resolve
   aliases to hex.
2. Then build artboards one at a time in file-name order (01, 02 … 23). For each:
   - Create an artboard with the meta name and size.
   - Rebuild the page with the same structure and flex layouts. Resolve CSS
     variables from design/tokens/tokens.css and the classes from
     design/components/*.css and design/frames/_board.css.
   - Place the SVGs from design/brand/ as vectors, not bitmaps.
   - Display text is Archivo from Google Fonts at width 68, weight 850. UI text is
     the system sans (SF Pro) and mono (SF Mono).
   - Compare your artboard with design/renders/<same name>.webp and fix any
     differences before starting the next one.
3. Lay artboards out left to right in three rows, 200 px apart:
   row 1: 01–05 (foundations and brand), row 2: 10–14 (plugin), row 3: 20–23 (site).
4. Stop after each row and tell me which artboards are done.

Open threads

Paper import

Run the prompt above on your Mac with Paper open.

ARA 2 or not

Click-to-jump needs ARA 2’s playback controller. A standard insert can read the host clock but can’t move it.

Syllable timing

The Flow Grid and syllable fill need syllable onsets. The engine returns word start and end today.

Implement the restyle

Swap token values in the plugin and site CSS, add the SVGs, update HANDOFF.md’s token table.

Activation is unmeasured

Install, first punch, first correction, and sign-in send no events. Any fix needs an honest opt-in on free.

Shaders in the real plugin and site

Embed p2p-shaders.js in the WebView and have the bridge dispose the smoke when the transport moves. The site needs one module script.

Remote MCP

Paper lists it as coming soon. Then a cloud session could build the canvas itself.

Marks are v1

Vector readings of your sketches. Iterate in Paper, then carry changes back into build_marks.py.
