DAW integration

In the session. On the host clock.

What ships is a Mac plugin: VST3 and AU, plus a local engine on that Mac. The host we actually run is Logic. The Living Transcript follows the playhead. A correction stays in the session, or lands in a signed-in dictionary.

Technical specs

What the plugin and the engine actually do.

Identity
Manufacturer Dcta, plugin P2pn, AU type aufx. Bundle ID com.doctaaa.punch2pen. Display name Doctaaa: punch2pen. Those codes stay.
Editor
Studio Receipt, one WebView inside the plugin. Default size 400×600, resizable. States you will see: WAIT while the engine is down, then IDLE, REC, and PLAY.
Capture
The plugin takes audio only while the host transport reports recording. Playback does not send a new take. It moves the playhead across words you already have.
Clock
Word times are sample start and end from the engine. Bar and beat come from the DAW. That clock lives in the plugin. The profile does not store it.
Living Transcript
During playback the word under the playhead is marked, and the active line is the title. Scroll away and you can return to live. While recording, the newest line is the title and the words are still provisional.
Link to the engine
Local TCP 127.0.0.1:7483. The plugin and punch2penEngine handshake, then audio, transport stop, and corrections move on that socket. Nothing in the free utility leaves the Mac.
Model
Local whisper.cpp. The file is ~/.punch2pen/models/ggml-base.bin. It is not baked into the pkg. Postinstall downloads it when it is missing; if you are offline, place the file yourself.
Correction
Click a word. A sheet docks under the transcript. Apply replaces every exact, case-sensitive match in the take and sends the pair to the engine. Cancel or Esc sends nothing. Free keeps the pair in a session dictionary in memory. Pro writes it on the signed-in seat. There is no separate dictionary editor.

Install, the nested engine helper, and the dictionary are written out on the docs page.
