Privacy

What this site does with data

Punch2Pen is a downloadable DAW plugin. This website is the public face: the plugin, the plans, studios, docs, and a sign-in page that does not accept a login. It is not the engine and it never hears your voice.

  • No accounts on this site. Free / lite install does not require a login. The sign-in page explains email-code delivery and does not collect an email, a code, or a password.
  • Voice stays off this domain. Local transcription runs on your Mac. This page does not upload audio.
  • Hosting. Cloudflare serves this site and receives normal HTTP request data.
  • Product network use. Free local transcription keeps audio and corrections on the Mac after setup. The installer downloads a Whisper model from Hugging Face when missing; that host receives the download request. A configured signed-in profile syncs correction pairs; an explicitly configured cloud transcription mode sends audio to OpenAI. This website does not enable either mode.
  • Analytics. Every page on this site loads PostHog. It records page views, clicks, download clicks, DAW self-report, “I would pay” / waitlist interest, page performance, and JavaScript errors. Session replay is on: PostHog records how the page was used (scrolls, clicks, page changes) so it can be played back, with every form field masked. PostHog receives request information and uses cookies and local storage for visitor identity. Requests from bots and crawlers are labeled as bots instead of dropped, so the site can count human and machine visits separately.
  • Waitlist email is only sent to PostHog when analytics is live. If analytics is off, the form tells you the address was not stored.
  • Creators form does not leave the browser. Applications are not open, and submitting it does not store the note.
  • Download is the macOS installer from the GitHub Release for keeganmoody33/punch2pen. The homepage also asks GitHub which Release is current so the button can name the pkg. GitHub sees those requests.
  • Type. Headlines use Archivo and body text uses Inter, both self-hosted on this domain (SIL Open Font License). The site does not call a font service.

This is not a full legal policy. One will live here before ads or a charge. Questions: use the repository issue tracker. Do not include private audio or credentials.
