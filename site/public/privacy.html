Privacy

What this site does with data

Punch2Pen is a downloadable DAW plugin. This website is only the public face: problem, download, free vs paid. It is not the engine and it never hears your voice.

  • No accounts on this site. Free / lite install does not require a login.
  • Voice stays off this domain. Local transcription runs on your Mac. This page does not upload audio.
  • Analytics. If a PostHog project key is configured on the host, we record page views, download clicks, DAW self-report, and “I would pay” / waitlist interest. If that key is missing, those events are wired in the page and do not leave the browser.
  • Waitlist email is only sent to PostHog when analytics is live. If analytics is off, the form tells you the address was not stored.
  • Download is the macOS installer from the GitHub Release for keeganmoody33/punch2pen. GitHub sees the download request.

This is not a full legal policy. One will live here before ads or a charge. Questions: open a GitHub discussion on the repo.
