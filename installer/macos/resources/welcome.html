Punch2Pen

This package installs the unsigned macOS AU and VST3 plugin plus the local punch2penEngine companion process.

  • AU: /Library/Audio/Plug-Ins/Components/punch2pen.component
  • VST3: /Library/Audio/Plug-Ins/VST3/punch2pen.vst3
  • Engine app: /Applications/Punch2Pen/punch2penEngine.app (also nested in the AU/VST3 bundle)
  • Engine CLI: /Applications/Punch2Pen/punch2penEngine (whisper/ggml dylibs sit next to it when not statically linked)
  • Login helper: /Library/LaunchAgents/com.doctaaa.punch2pen.engine.plist (RunAtLoad, no KeepAlive)

Local transcription needs a Whisper model at ~/.punch2pen/models/ggml-base.bin. The installer downloads that model when it is missing (network required). No vendor API keys are included.

The plugin is not sandbox-safe. It talks to the engine over 127.0.0.1:7483. GarageBand may refuse it; Logic, REAPER, and Ableton are the intended hosts.
