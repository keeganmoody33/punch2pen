Punch2Pen

This package installs the unsigned macOS AU and VST3 plugin plus the local punch2penEngine companion process.

  • AU: /Library/Audio/Plug-Ins/Components/punch2pen.component
  • VST3: /Library/Audio/Plug-Ins/VST3/punch2pen.vst3
  • Engine: /Applications/Punch2Pen/punch2penEngine

Local transcription needs a Whisper model at ~/.punch2pen/models/ggml-base.bin. This installer does not download a model and does not contain any vendor API keys.

The plugin is not sandbox-safe. It talks to the engine over 127.0.0.1:7483. GarageBand may refuse it; Logic, REAPER, and Ableton are the intended hosts.
